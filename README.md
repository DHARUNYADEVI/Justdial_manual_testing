# Justdial Manual Testing Project
## Name: Dharunyadevi S
## Register Number: 212223220018
## Project Overview

This project contains manual test cases developed for testing the Justdial website.

The objective of this project is to validate important user functionalities such as login, search, location selection, business listings, filters, reviews, calling, directions, sharing, favorites, and logout.

## Website Under Test

Justdial  
https://www.justdial.com/

## Testing Type

- Manual Testing
- Functional Testing
- UI Testing
- Positive Testing
- Negative Testing
- Validation Testing

## Test Environment

- Browser: Google Chrome / Microsoft Edge / Mozilla Firefox
- Platform: Windows
- Application: Justdial Website

## Test Scenarios Covered

1. Login with valid mobile number and OTP
2. Login with invalid OTP
3. Login with invalid mobile number
4. Search with valid keyword
5. Search with no results
6. Search with blank keyword
7. Change search location
8. View business search results
9. Open business profile
10. Apply search filters
11. Sort search results
12. View business photos
13. View ratings and reviews
14. Submit a business review
15. Call a business
16. Get directions
17. Share business listing
18. Add business to favorites
19. Logout
20. Free business listing flow

## Test Case Format

Each test case contains:

- Requirement ID
- Test ID
- Test Scenario / Feature
- Preconditions
- Test Data
- Environment
- Test Steps
- Expected Result

## Deliverables

The repository contains the Excel file with detailed manual test cases.
